# AutoResidualTag

!syntax description /AutoResidualTag/AutoResidualTagAction

The `[AutoResidualTag]` block creates one residual tag per Kernel and boundary condition and adds the DEIM snapshot containers on a full-order model. See [AutoResidualTagAction.md] for details and [modules/stochastic_tools/examples/deim_rom.md] for the method.

!syntax list /AutoResidualTag objects=False actions=True subsystems=False
